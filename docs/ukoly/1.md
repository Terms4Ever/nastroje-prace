# Zavedení první pracovní sady

## Zadání

Založit privátní repozitář s jednotnými pravidly, kontrolami a testy.
Instalace nesmí měnit společné nastroje ani jiné existující projekty.

## Změna

Vzniká samostatné Python CLI s připnutými společnými PHP validátory,
lokálními hooky, kontrolami issues, dokumentace, commitů a důkazů ověření.
SVN adaptér připravuje místní balíček a ověřuje stav a výslednou revizi.
Workflow prověřují Windows, Linux a aktuální issues.

## Ověření

Sada zahrnuje pozitivní i negativní případy a izolované skutečné SVN
integrační scénáře na Linuxu. Konkrétní výsledek patří běhu GitHub Actions
příslušného commitu a místnímu protokolu. Dokončení issue vyžaduje úspěšné
CI a online ověření stejné verze.

## Předání

Výstupem je privátní GitHub repozitář nastroje-prace a místní instalace hooků.
Pracovní aplikace zatím nejsou připojené. Nejde o vizuální změnu aplikace;
důkazem jsou kontrolní scénáře a běhy CI, nikoli snímky rozhraní.
