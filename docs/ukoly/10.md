# Úkol 10: Veřejné nástroje a privátní aplikace

## Zadání

Vlastník výslovně požaduje veřejný nastroje-prace. Důležitý pracovní obsah
bude přímo v jednotlivých privátních projektech. Technický úkol bez Mantis.

## Změna

Centrální kořen nástrojů připouští veřejnou viditelnost, aplikace nadále
vyžadují privátní GitHub. Návody popisují oddělení obecné sady od pracovních
zdrojů, zadání a snímků. Distribuce připnutou kopií a proprietární licence
se nemění. Nepřevzaté veřejné podněty a komentáře návštěvníků neblokují audit,
převzaté úkoly a zápisové vstupy agenta dál vyžadují plný tvar.

## Ověření

Osm cílených scénářů prošlo včetně odmítnutí veřejné aplikace, chybné identity
a pokusu použít veřejný podnět jako neúplný vstup agenta. Před zveřejněním
prošlo [CI verze 0.6.0](https://github.com/Terms4Ever/nastroje-prace/actions/runs/35967404975):
Linux ověřil 100 testů včetně skutečného SVN, Windows 91 testů a devět SVN
scénářů přeskočil kvůli chybějícímu CLI. Místní kontrola měla stejný výsledek
jako Windows CI. Prověrka před zveřejněním zahrnula 14 commitů, 251 souborových
objektů, deset issues a 132 dostupných protokolů bez chyby jejich načtení.
Použité detektory nezachytily přihlašovací údaje ani interní adresy; historické
zmínky názvů projektů a obecný příklad místní cesty zůstávají známým obsahem.
Nejde o důkaz neexistence libovolného tajemství.

## Předání

GitHub 24. 9. 2026 potvrdil veřejnou viditelnost. Anonymní požadavky přečetly
metadata repozitáře, README i PHP runtime; obsah souborů odpovídal publikovanému
commitu. Skutečné snímky stránky před zveřejněním a po něm jsou ve složce
docs/snimky/10-public. Dokončení úkolu vyžaduje místní kontroly, úspěšné CI
a anonymní ověření také pro commit s těmito důkazy. Pracovní aplikace ani
firemní SVN nebyly změněny.
