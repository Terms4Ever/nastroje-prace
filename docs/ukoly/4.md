# Úkol 4: Úklid dokončených větví

## Zadání

Po dokončení práce zůstaly tři převzaté pracovní větve a jedna větev s úmyslně
chybným testem. Vlastník požaduje přehledný repozitář bez těchto zbytků.
Jde o technický úkol bez Mantis.

## Změna

Odstraněny větve oprava/php-a-readme, zavedeni/overeni, zavedeni/pravidla-projektu
a overeni/zamitnuta-zmena. GitHub má zapnuté delete_branch_on_merge=true.
Pravidla agenta a postup založení projektu vyžadují úklid vlastních dokončených
větví na GitHubu i místně. Main je trvalá větev, ostatní slouží rozpracovaným úkolům.

## Ověření

U tří větví byla potvrzena přítomnost jejich commitů v main. Neexistoval otevřený
pull request. Negativní větev měla pouze testovací soubor overeni-bez-zaznamu.txt;
její commit 6f003acbfb1b2f1d6e5280cfc4faf9bb9fbb6e22 byl před odstraněním uložen
do místní ověřené Git bundle zálohy. Důkaz odmítnutí zůstává v
[původním CI](https://github.com/Terms4Ever/nastroje-prace/actions/runs/35862427227).
Odstranění vzdálených větví podmiňovalo shodné aktuální SHA. Obsah main se
při úklidu nezměnil. Nastavení mazání bylo potvrzeno zpětným čtením GitHub API.
Změna pravidel prochází povinným místním check a CI na Windows a Linuxu.

## Předání

Dokončení zahrnuje také odstranění pracovní větve tohoto úkolu po přijetí
na main. Privátní viditelnost, ochrana main a obsah ostatních repozitářů se
nemění. Automatické mazání GitHubu platí pro sloučené pull requesty; ostatní
případy a místní větve uklízí agent podle pravidel.
