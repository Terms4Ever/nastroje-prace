# Záznamy úkolů

Každý úkol má soubor ČÍSLO.md podle skutečného čísla GitHub issue, se sekcemi
Zadání, Změna, Ověření a Předání. Metadata patří do .tasks/ČÍSLO.json.

Hlavní README odkazuje na tuto složku, nikoli na každý jednotlivý úkol.
Průběh a otevřené úkoly se hledají v GitHub Issues. Stav architektury a návody
patří do tematických dokumentů v docs/, nikoli do rostoucího seznamu úkolů v README.
