# Úkol 6: Jednotná podoba README

## Zadání

Po dokončení režimu pouze main vlastník požádal prověřit rozdílnou podobu
README. Srovnání používá aktuální nastroje a skutečné vykreslení na GitHubu.

## Změna

Hlavní README i šablona používají strom souborů, tabulku Vrstva a Technologie,
krátké popisy funkcí a příkazy v kódových blocích. Dokumentace má klikací
odkazy s krátkými názvy a jediný odkaz na záznamy úkolů. Příkazy mimo kód
už neztrácejí zpětná lomítka při vykreslení. Odznak CI odkazuje na workflow.

Instalace popisuje současnou verzi; historické přechody patří do návodu
aktualizace. Šablona rozlišuje technologie aplikace od PHP pracovních kontrol
a postup zavedení vyžaduje popis skutečných funkcí a instalace aplikace.
Původní nastroje ani verze připnutých kontrol se nemění.

## Ověření

Původní stav byl zachycen ve stejném prohlížeči proti původním nástrojům.
Snímky před úpravou zachycují strukturu s dokumentací a instalaci; protějšky
po úpravě se doplní ze skutečného GitHubu po prvním pushi. Kontrola README
ověřuje pořadí sekcí i existenci cest a odkazů. Export šablony se ověřuje
stávajícím testem izolované aplikace a čistého clone.

## Předání

Změna se předává přímo na main. Dokončení issue 6 vyžaduje místní online
kontrolu, úspěšné CI stejného main a vložené dvojice snímků s neměnnými
odkazy. Konečný komentář issue dokládá ověření konkrétního commitu.
