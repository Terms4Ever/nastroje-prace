# Úkol 7: Schválená pracovní pravidla

## Zadání

Vlastník schválil odstranění ochrany main a denního auditu issues, stručné
vlastní nápady bez šablony, výjimku pro skutečně nepořiditelný snímek a původní
výjimku pomlček citovaných v řádkovém kódu dokumentace. Technický úkol bez Mantis.

## Změna

Kontroly a šablony přebírají schválená rozhodnutí. Formální kontrola
agenta zůstává povinná při založení, převzetí a dokončení úkolu. Ochranu main
nenastavuje ani nevyžaduje postup napojení. Denní plán se odstraňuje, ostatní
události kontrol zůstávají. Dokumentace přijímá původní výjimku pomlčky
v řádkovém kódu.

Vlastník následně výslovně určil, že každou výjimku snímků schvaluje on.
Žádost obsahuje přesné chybějící cesty, překážku, pokus a verzované důkazy.
Živý komentář vlastníka musí odpovídat otisku podkladů; agent smí souhlas
z chatu pouze zaznamenat po skutečném rozhodnutí. Ostatní snímky zůstávají
povinné. Samotný štítek, neúplné podklady ani odvolaný souhlas nestačí.

## Ověření

Sedm nových scénářů pokrývá schválené změny a jejich hranice. Před úpravou
implementace čtyři scénáře selhaly na původním chování, po opravě prošly všechny.
Po doplnění dvanácti scénářů výjimky místní celá sada ověřila 80 scénářů bez
chyby; devět SVN scénářů se kvůli chybějícímu SVN CLI výslovně přeskočilo.
Zahrnuje export pravidel, skutečné hooky a čistý clone. Výjimka má pozitivní
i negativní případy, včetně odvolaného souhlasu těsně před dokončením a změny
podkladů. Živý audit ověřil všech sedm dosavadních issues. GitHub CI konkrétního
commitu doloží komentář issue po doběhnutí.

## Předání

Změna patří pouze do nastroje-prace a jeho šablon. Repo zůstává privátní,
pracovní aplikace se zatím nepřipojují. Dokončení issue vyžaduje ověřený main
a skutečné potvrzení odstraněné ochrany přes GitHub API. Issue zůstane otevřené,
dokud neprojde ověření dokončené výjimky snímků stejného commitu.
