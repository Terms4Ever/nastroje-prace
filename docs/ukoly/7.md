# Úkol 7: Schválená pracovní pravidla

## Zadání

Vlastník schválil odstranění ochrany main a denního auditu issues, stručné
vlastní nápady bez šablony, výjimku pro skutečně nepořiditelný snímek a původní
výjimku pomlček citovaných v řádkovém kódu dokumentace. Technický úkol bez Mantis.

## Změna

Kontroly a šablony nyní přebírají čtyři samostatná rozhodnutí. Formální kontrola
agenta zůstává povinná při založení, převzetí a dokončení úkolu. Ochranu main
nenastavuje ani nevyžaduje postup napojení. Denní plán se odstraňuje, ostatní
události kontrol zůstávají. Dokumentace přijímá původní výjimku pomlčky
v řádkovém kódu.

Výjimka snímku je samostatná zbývající část: vlastník rozhoduje v dialogu,
zda každý doložený případ potvrzuje on, nebo může po doložení rozhodnout agent.
Do tohoto rozhodnutí implementace dál vyžaduje snímky a žádnou výjimku nepovoluje.

## Ověření

Sedm nových scénářů pokrývá schválené změny a jejich hranice. Před úpravou
implementace čtyři scénáře selhaly na původním chování, po opravě prošly všechny.
Místní celá sada ověřila 68 scénářů bez chyby; devět SVN scénářů se kvůli
chybějícímu SVN CLI výslovně přeskočilo. Zahrnuje export pravidel, skutečné hooky
a čistý clone. GitHub CI konkrétního commitu doloží komentář issue po doběhnutí.

## Předání

Změna patří pouze do nastroje-prace a jeho šablon. Repo zůstává privátní,
pracovní aplikace se zatím nepřipojují. Dokončení issue vyžaduje ověřený main
a skutečné potvrzení odstraněné ochrany přes GitHub API. Issue zůstane otevřené,
dokud nebude dokončená i výjimka snímků podle rozhodnutí vlastníka.
