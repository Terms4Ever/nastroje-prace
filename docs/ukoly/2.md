# Úkol 2: PHP, README a GitHub topics

## Zadání

Sjednotit jazyk kontrol se společnými PHP nástroji. Opravit chybějící topics
a pořadí README. Vlastník výslovně zvolil převod celého jádra a testů do PHP.

## Změna

PHP vstupní bod prace.php nahrazuje původní modul. PowerShell spouští PHP a
instaluje místní runtime s kontrolou SHA-256. Hooky a oba workflow používají PHP.
README má Dokumentaci před Instalací; nové pravidlo kontroluje i úplný check.
Online ověření porovnává privátní viditelnost a topics s konfigurací projektu.
Aktuální pravidla a postupy jsou v AGENTS.md a příslušných dokumentech.

## Ověření

PHP sada zachovává původní scénáře a přidává regrese pořadí README, metadat,
procesů na Windows a dokončení issue. Linux CI vyžaduje skutečné dočasné SVN.
Konkrétní výsledky pro předávaný commit jsou v Actions a místním dokladu check.
Záměrně chybný vstup musí skončit chybou; chybějící SVN CLI je výslovné přeskočení.

## Předání

Předání probíhá pouze v privátním nastroje-prace přes ověřenou pracovní větev
a chráněný main. W4SN, DOMIQ, společné nastroje ani jiné repozitáře se nemění.
Issue lze uzavřít až po splnění checklistu a kontrolách stejného commitu.
