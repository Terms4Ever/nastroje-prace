# Úkol 8: Jednotná tabulka dokumentace

## Zadání

Vlastník doložil snímkem odlišné formátování dokumentace mezi nastroje
a nastroje-prace. Tabulka pracovního README používá jiné názvy a jiný text
pod tabulkou, přestože má držet společný formát. Technický úkol bez Mantis.

## Změna

README a šablona používají cesty v řádkovém kódu, společné popisy dvou
základních dokumentů a větu určující aktuální stav projektu. Další řádky
odpovídají skutečným dokumentům projektu; záznamy úkolů zůstávají jednou složkou.
Kontrola README ověřuje i tento tvar tabulky. Vzorem je původní nastroje
na commitu 6792504352ec4d2fb7d28150b3e4718969dc4783, který se touto změnou neupravuje.

## Ověření

Původní vzhled zachycuje snímek z GitHubu před úpravou. Tři nové scénáře prošly:
ověřují sjednocený README a odmítnutí pojmenovaných odkazů, chybějící věty
a odlišných společných popisů.
Vykreslení výsledného README a úplné CI budou doloženy v issue před dokončením.

## Předání

Změna patří do centrálních pracovních nástrojů a šablony budoucích projektů.
Issue se uzavře až se snímky před a po, místním ověřením a úspěšným CI
stejného aktuálního main. Jiný repozitář se kvůli této opravě nemění.
